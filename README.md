# 摸鱼时钟 🐟

一个记录每天**专注多久、摸鱼多久**的单文件 HTML 小工具。纯前端实现，零依赖（除 ECharts CDN），双击即用的"电子工位打卡机"。

## 功能

- **一键切换**：一个按钮在"专注 ⇄ 摸鱼"之间切换，空格键快捷操作，Esc 暂停/继续
- **时间戳计时**：基于时间差计算，页面切后台、刷新、关页面重开都不会丢时间
- **自动跨天**：计时跨过午夜自动拆分统计到两天
- **今日曲线**：ECharts 平滑曲线，8:00–18:00 为基准时间轴，加班自动向右延长
- **最近 7 天**：ECharts 堆叠柱状图，每天专注/摸鱼占比一目了然，悬停查看摸鱼率
- **今日时间线**：每次专注/摸鱼的起止时刻和时长
- **桌面提醒**：专注满 2 小时提醒休息，摸鱼满 30 分钟提醒干活
- **一键复制**：今日战绩 / 本周战报文案，直接发群
- **数据持久化**：`localStorage` 每 10 秒自动保存，支持导出 JSON 备份
- **示例数据**：一键填充最近 7 天模拟数据，快速预览图表效果

## 使用

直接用浏览器打开 `index.html` 即可（图表功能需要联网加载 ECharts）。

| 操作 | 效果 |
|---|---|
| 点击主按钮 / 空格 | 开始 / 切换专注·摸鱼 |
| Esc / 暂停按钮 | 暂停 / 继续 |

## 技术要点

- 单文件实现：HTML + CSS + 原生 JS，无构建步骤
- 计时采用 `Date.now()` 时间戳差值结算，而非 `setInterval` 计数，免疫浏览器后台标签页降频
- 数据模型：`{ 'YYYY-MM-DD': { focus, slack, sessions: [{mode, start, end}] } }`
- 图表：ECharts 5（CDN 引入）

## 数据说明

所有数据保存在浏览器 `localStorage`（键名 `moyu-clock-v1`），清理浏览器数据会丢失，建议定期用"导出数据"备份。
